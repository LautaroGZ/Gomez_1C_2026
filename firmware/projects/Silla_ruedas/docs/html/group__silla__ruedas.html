Silla de Ruedas controlada por la inclinación de la mano.
Sistema de control de silla de ruedas eléctrica mediante acelerómetro y Bluetooth Low Energy. Implementado sobre ESP32-C6 y FreeRTOS, permite adquirir datos de inclinación, controlar motores DC a través de un L293, indicar estados mediante LEDs y gestionar la habilitación remota del sistema desde una aplicación móvil.

◆ app_main()

void app_main ( void )

Punto de entrada principal de la aplicación.

Inicializa los periféricos necesarios para el funcionamiento del sistema:

  • UART para transmisión de datos.
  • ADC para adquisición del acelerómetro.
  • LEDs indicadores.
  • Driver de motores L293.
  • Bluetooth Low Energy.

Posteriormente crea las tareas de FreeRTOS encargadas de:

  • Adquisición de datos.
  • Control de motores y LEDs.

Una vez creadas las tareas, el scheduler de FreeRTOS toma el control de la ejecución.

◆ Control_Motores_Leds()

void Control_Motores_Leds ( void * pvParameter)

Tarea de control de motores y señalización mediante LEDs.

Evalúa continuamente el valor adquirido por el acelerómetro y el estado de habilitación recibido por BLE.

Dependiendo del rango de inclinación detectado:

  • Retroceso.
  • Avance.
  • Detención.

Además implementa una condición de parada segura cuando la silla se encuentra deshabilitada.

◆ leer_data_bluetooth()

void leer_data_bluetooth ( uint8_t * data,
uint8_t length )

Procesa los comandos recibidos mediante Bluetooth Low Energy.

La función es invocada automáticamente por la pila BLE cuando se reciben datos desde una aplicación móvil.

Comandos soportados:

  • 'C' : habilita el movimiento de la silla.
  • 'c' : deshabilita el movimiento de la silla.

[in]dataBuffer con los datos recibidos.

◆ TaskAccel()

void TaskAccel ( void * pvParameter)

Tarea de adquisición y transmisión de datos del acelerómetro.

Lee periódicamente el canal analógico CH1 conectado al acelerómetro ADXL335 y almacena el resultado en la variable global valor_accel.

Posteriormente transmite la muestra por UART

Tiempo de ejecución: -20 ms.
