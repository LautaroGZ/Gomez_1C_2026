Punto de entrada principal de la aplicación. 

Inicializa los periféricos necesarios para el funcionamiento del sistema:\+


\begin{DoxyItemize}
\item UART para transmisión de datos.
\item ADC para adquisición del acelerómetro.
\item LEDs indicadores.
\item Driver de motores L293.
\item Bluetooth Low Energy.
\end{DoxyItemize}

Posteriormente crea las tareas de Free\+RTOS encargadas de:\+
\begin{DoxyItemize}
\item Adquisición de datos.
\item Control de motores y LEDs.
\end{DoxyItemize}

Una vez creadas las tareas, el scheduler de Free\+RTOS toma el control de la ejecución. \Hypertarget{group__silla__ruedas_ga3ced46c3d303a002351b1df4a28e3a2d}\index{Sistema de control de silla de ruedas@{Sistema de control de silla de ruedas}!Control\_Motores\_Leds@{Control\_Motores\_Leds}}

Tarea de control de motores y señalización mediante LEDs. 

Evalúa continuamente el valor adquirido por el acelerómetro y el estado de habilitación recibido por BLE.

Dependiendo del rango de inclinación detectado:\+
\begin{DoxyItemize}
\item Retroceso.
\item Avance.
\item Detención.
\end{DoxyItemize}

Además implementa una condición de parada segura cuando la silla se encuentra deshabilitada.
