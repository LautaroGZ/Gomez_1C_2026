\doxysubsection{Detailed Description}
Sistema de control de una silla de ruedas mediante acelerómetro y Bluetooth Low Energy. 

El programa implementa un sistema para controlar el movimiento de una silla de ruedas eléctrica utilizando un acelerómetro analógico ADXL335 como dispositivo de entrada y Bluetooth Low Energy (BLE) como mecanismo de habilitación remota.

El sistema ejecuta tareas concurrentes para:\+
\begin{DoxyItemize}
\item Adquirir continuamente la señal analógica del acelerómetro.
\item Transmitir los datos adquiridos por UART para monitoreo.
\item Determinar el sentido de movimiento según la inclinación detectada.
\item Accionar dos motores DC mediante un controlador L293.
\item Indicar visualmente el estado mediante LEDs.
\item Habilitar o bloquear el movimiento desde una aplicación móvil vía BLE.
\end{DoxyItemize}

Funcionamiento:\+
\begin{DoxyItemize}
\item Si la silla está habilitada mediante Bluetooth:\+
\begin{DoxyItemize}
\item Inclinación en rango alto -\/\texorpdfstring{$>$}{>} retroceso.
\item Inclinación en rango bajo -\/\texorpdfstring{$>$}{>} avance.
\item Posición intermedia -\/\texorpdfstring{$>$}{>} detención.
\end{DoxyItemize}
\item Si la silla está deshabilitada:\+
\begin{DoxyItemize}
\item Motores detenidos.
\item LEDs apagados.
\end{DoxyItemize}
\end{DoxyItemize}

El sistema utiliza una arquitectura multitarea basada en Free\+RTOS, donde la adquisición de datos y el control de movimiento se ejecutan en tareas independientes.
