General Description

Aplicación de medición de distancia con sensor ultrasónico HC-SR04. El sistema utiliza un timer de hardware y una tarea FreeRTOS para realizar mediciones periódicas y actualizar un display LCD.

Hardware Connection

Peripheral ESP32
HC-SR04 TRIG GPIO_3
HC-SR04 ECHO GPIO_2
LCD ITS E0803 GPIO / I2C
SWITCH_1 Configurado en driver
SWITCH_2 Configurado en driver
